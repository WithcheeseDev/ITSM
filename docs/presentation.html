Requestor

สมชาย · พนักงาน

  • เห็น: เรื่องตัวเอง + แจ้งแทน
  • ทำ: แจ้ง · ติดตาม · ยกเลิก · Re-open

Approver

ปรีชา / อรุณี · หัวหน้า

  • เห็น: เรื่องตัวเอง + คำขอรออนุมัติ
  • ทำ: อนุมัติ / ปฏิเสธ + comment

Agent

ธนา · Service Desk

  • เห็น: เรื่องในคิวกลุ่มตัวเอง
  • ทำ: Assign · เปลี่ยนสถานะ · ปิดงาน

Admin

ผู้ดูแลระบบ

  • เห็น: ทุกเรื่อง (อ่านอย่างเดียว)
  • ทำ: ตรวจ Timeline · ดูแลข้อมูลอ้างอิง
