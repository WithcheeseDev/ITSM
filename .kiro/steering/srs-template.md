# Software Requirements Specification (SRS) - Metro Systems Corporation Plc.

ใช้โครงเอกสารนี้เมื่อต้องเขียนหรือตรวจ SRS ให้ครบทุกหัวข้อตามลำดับ

## Document Outline

1. Cover Page (หน้าปก)
2. Approval (การอนุมัติ)
3. Revision History (ประวัติการแก้ไข)
4. Table of Contents (สารบัญ)
5. Introduction (บทนำ)
6. Overall Description (คำอธิบายโดยรวม)
7. Specific Requirements (ข้อกำหนดเฉพาะ)
   - 7.1 As-Is (สถานะปัจจุบัน)
   - 7.2 Plan Point (จุดที่ต้องการพัฒนา / To-Be)
   - 7.3 Functional Requirements (ข้อกำหนดเชิงฟังก์ชัน)
   - 7.4 Non-Functional Requirements (ข้อกำหนดที่ไม่ใช่เชิงฟังก์ชัน)
8. Use Cases (กรณีใช้งาน)
9. External Interface Requirements (ข้อกำหนดส่วนติดต่อภายนอก)
10. System Architecture Overview (ภาพรวมสถาปัตยกรรมระบบ)
11. Appendix (ภาคผนวก)
